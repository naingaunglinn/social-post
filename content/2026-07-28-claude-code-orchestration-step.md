## §4 LinkedIn caption

Most teams use Claude Code like a faster chat window. The leverage is one step further out.

A single agent in a single context has a built-in flaw: it grades its own work. It anchors on
its first idea and defends it to the end of the context window — the same reason authors make
poor reviewers of their own code.

The orchestration step fixes the incentive structure instead of the prompt:

— Scout the codebase with parallel readers before anyone writes code
— Fan out one agent per concern, so no single context has to hold everything
— Verify adversarially: separate agents whose only job is to refute each finding
— Merge into one ranked synthesis a human can actually review

Not every task earns this. A one-file fix wants one agent. But audits, migrations, and reviews —
anything where being wrong is expensive — deserve independent checks, not a confident monologue.
